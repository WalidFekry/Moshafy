## 🌟 نبذة عن التطبيق

**مُصحفي** هو تطبيق أندرويد إسلامي شامل مصمم بأسلوب عصري وبسيط، يتيح لك قراءة القرآن الكريم بالرسم العثماني الأصلي، والاستماع لأشهر القراء عبر الإنترنت وفي الخلفية، مع الأذكار والمسبحة الإلكترونية والقصص الإسلامية، بدون إعلانات مزعجة وبدعم كامل للوضعين الداكن والفاتح.

---

## 📌 الأقسام الرئيسية

- 📖 **القرآن الكريم (قراءة):** قراءة عثمانية دقيقة، فهرس السور والأجزاء، العلامات المرجعية، البحث الفوري، وإكمال القراءة من حيث توقفت.
- 🎧 **القرآن الكريم (استماع):** تلاوات لأكثر من 200 قارئ عبر API موثق، مع مشغل صوتيات يعمل في الخلفية وشاشة القفل، والتحكم بالسرعة والتكرار.
- 📿 **أذكار المسلم:** أذكار الصباح والمساء والصلاة والنوم، مع عداد تكرار تفاعلي وتنبيه اهتزازي.
- 📿 **المسبحة الإلكترونية:** عداد تسبيح تفاعلي باهتزاز تلمسي وأذكار مسبقة الضبط وحفظ تلقائي للتقدم.
- 🌿 **آية الكرسي والرقية الشرعية:** قراءة واستماع وتصميم مزخرف، ورقية شرعية كاملة بدون إنترنت.
- 📜 **منوعات إسلامية:** أحاديث نبوية قصيرة من الصحيحين، وسنن مهجورة، وأحكام الحج والعمرة.
- 📖 **قصص الصحابة والإسلامية:** مكتبة قصصية هادفة وسهلة القراءة.
- 💌 **رسائل وإشراقات يومية:** اقتباسات وبطاقات صور HD جاهزة للمشاركة في التواصل الاجتماعي.

---

## ⚡ المميزات التقنية

- 🎨 **تصميم حديث وعصري:** دعم تكيّفي كامل للوضعين الليلي والنهاري (Dark & Light Mode) واتجاه RTL.
- ⚡ **أداء سريع واستجابة:** بناء الكود بـ ViewBinding و Java 17 و Room Database.
- 🎵 **تشغيل الصوت في الخلفية:** دعم كامل لـ AndroidX Media3 ExoPlayer و Foreground Service.
- 📡 **دعم الأوفلاين:** حفظ البيانات والأذكار محلياً لتصفح سريع بدون إنترنت.
